# Dashboard descriptivo de turnover

Producto analítico descriptivo en Streamlit para explorar el turnover de la muestra de People Analytics.

## Archivos del repositorio
- `app.py`: aplicación Streamlit.
- `HR_Analytics_Dashboard.xlsx`: base dummy.
- `requirements.txt`: dependencias.
- `.streamlit/config.toml`: colores del dashboard.
- `INFORME_LABORATORIO.md`: problema, objetivos, variables, hallazgos, hipótesis y recomendaciones.

## Despliegue
En Streamlit Community Cloud seleccionar el repositorio, la rama `main` y el archivo `app.py`.

## Alcance
El análisis es descriptivo. Las asociaciones no demuestran causalidad y no deben usarse para decisiones individuales de empleo.
